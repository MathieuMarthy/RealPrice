## 描述

RealPrice是一款适合想要了解外币商品真实成本的旅行者的必备货币转换应用。使用RealPrice，您可以轻松比较两种货币之间的汇率，并调整银行在国际交易时收取的佣金百分比。此功能让您可以计算商品或服务的最终价格，不仅考虑汇率，还考虑相关的银行费用。该应用在您连接到互联网时会自动更新，确保始终准确和最新的转换。不要再在没有RealPrice的情况下旅行了！确保知道您在所选货币中的确切支出，考虑到银行的转换费用。立即<a href="https://github.com/MathieuMarthy/RealPrice/releases/latest">下载RealPrice</a>，安心旅行。

## 工作原理

RealPrice基于简单而有效的原理运作，为您提供准确和现实的货币转换：

### 🔄 **实时转换**
- 应用程序提供**200多种全球货币**及其当前汇率
- 一旦连接到互联网，汇率数据会自动更新
- 在离线模式下，应用使用最新下载的汇率，并显示最后更新日期

### 💰 **直观界面**
- **两个输入字段**允许双向即时转换
- 通过带有国旗和符号的下拉菜单**轻松选择货币**
- **双向转换**：在任何字段中输入金额即可看到自动转换
- **快速交换**：如果您选择已在使用的货币，两种货币会自动交换

### 📱 **高级功能**
- **自适应深色/浅色模式**
- **多语言支持**（提供9种语言）
- **移动数据管理**（启用/禁用移动网络更新）

### 🌐 **自动更新**
- 通过互联网每日验证汇率
- 本地数据备份供离线操作
- 连接状态的可视指示

## 配置

### 🏦 **银行费用计算**
RealPrice通过集成以下功能超越简单转换：
- **可定制佣金率**（根据您的银行的可变百分比）
- **固定费用**（每笔交易的固定金额）
- **佣金上限**（费用的最大限额）
- **计费货币**（选择费用适用的货币）
